# Temporary Android PR proof contract

Artifact-only draft. `manifest.json` is enabled only after the exact source/overlay tuple has been bound and reviewed. Do not publish or execute until the owner has supplied exact inputs, independent review and autoreview are clear, and root has approved the complete hash tuple.

The temporary fork branch is `codex/android-ten-pr-122200-proof`. It is rooted at trusted `9bd50c803cce88f2ab387ddaf6cc29b4ef004005`; no contributor runtime or workflow modifications are part of the tooling branch. Runtime source is fetched by full SHA from the public OpenClaw fork network. Each pushed tooling commit launches one fresh GitHub VM and tests exactly one source revision.

`overlay.patch` is the owner's reviewed test-only diff against the specified source SHA. It may touch only Kotlin files under app/src/test/java or app/src/androidTest/java, and every touched path must match overlayPaths exactly. The complete file SHA256 goes in overlaySha256. No production seam, Gradle dependency, environment configuration, wrapper or source-test relaxation is allowed in this overlay. A source-compatible existing test extension is preferred. Baseline and fixed runs should use identical tests; document any unavoidable mechanical adapter and do not treat compile errors as red behavior.

Unit mode requires explicit fully qualified Gradle test filters and a closed unique list of expected baseline failures, each with exact JUnit classname, name and distinctive expected assertion message. Every filter must match an observed test class or class.method. An empty expectedFailures list means every selected case must pass. Expected-red also requires the sole terminal Gradle failure to be the selected test task with failing tests. Any unrelated failure/error/skip, zero tests, missing XML, timeout or nonstandard command exit is invalid proof. Reports identify the app source plus test overlay, never a clean bare-head test claim. The complete raw Gradle log remains mandatory review input; the classifier is not malicious-source attestation.

Native mode requires an independently reviewed `native-driver.sh`, its SHA256, a native test overlay, and a nonempty unique nativeAssertions ID list. The driver runs only inside the disposable GitHub VM after the app and test APKs are built and installed into its fresh normal-framebuffer API36 guest. It receives PROOF_ADB, ANDROID_SERIAL, PROOF_APP_APK, PROOF_TEST_APK and PROOF_ARTIFACTS; no credentials. It must use only synthetic public fixtures, own/join all helper/instrumentation children, bound waits to visible/request state, retain app-only logs, and write native-result.json with result="pass" and an assertions array containing exactly the manifest IDs, each with outcome="pass", only after real assertions pass. Driver exits nonzero for any incomplete behavior. Do not dump all environment, user directories, whole logcat, or private data.

Required native behavior: long synthetic history with >8k assistant text, actual chat.message.get load, close/retry/typed unavailable, reused message ID in another session, gateway change, same-endpoint socket replacement and stale UI callback controls. Capture normal before/after framebuffers and relevant UI XML; proof readers individually inspect the images. API36 boot.png is precondition evidence, not app proof. A black or blank framebuffer invalidates visual evidence.

Driver captures use only `native-<lowercase-id>.png|xml|json|log|txt` directly under PROOF_ARTIFACTS. The trusted collector stages only its explicit root filename list, those bounded native names and `junit/TEST-<class>.xml`; no symlinks, other types or other directories. Limits are 128 entries, 16 MiB per file, 64 MiB total. Oversized or unknown outputs fail sealing and are not uploaded. APKs, HOME, caches and credentials are excluded. GitHub upload-artifact receives only the sealed staging directory. Capture files must still be inspected before being called visual proof or attached to the PR.

Before publishing, fill and validate all manifest fields, record file hashes, inspect other inherited workflows' push triggers, and run static actionlint/shellcheck/Python syntax checks without executing any contributor code. The workflow runs with permissions:{} and uses no repository secrets, environments, authenticated checkout, caches, hydration, paid runner, or cloud lease. Public standard GitHub-hosted runners provide the isolation; env-i merely limits accidental ambient propagation.

The same runner UID has administrative access: source can modify its workspace and subsequent tooling. Private directories, env-i, result classifiers and artifact staging are hygiene/proof checks, not an OS boundary or tamper-proof attestation. The disposable VM without user/repository credentials is the safety boundary; independent source review and inspection of raw evidence remain the proof authority.

SDK installation never accepts licenses. It uses only preaccepted runner SDK agreements and fails on absent/changed license state. Actual KVM, toolchain, package revision, free disk, image and framebuffer must be checked in the run. Do not fall back to personal machines or install these untrusted APKs locally. Delete only the owned fork branch after preserving artifact/run provenance; no main/default-branch or fork-settings changes.
