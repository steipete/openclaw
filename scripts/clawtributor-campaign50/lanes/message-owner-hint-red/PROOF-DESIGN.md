# Message CLI owner diagnostic baseline

This is a baseline-only experiment against protected original parent `2e3d04b6c84c0dfccb6866d9e0868c60f86aad33`, using Node24.20.0 and pnpm12.3.4. The incoming contributor code and proposed production rewrite are not applied or executed. The three candidate files are byte-identical at this base and the source-qualified main1029; package/lock differences between those trees are recorded separately rather than pretending they are one execution.

The real package executable is built with normal `pnpm build` and launched as `node <target>/openclaw.mjs`. Eight separately isolated processes cover ordinary send, dry-run send, profiled dry-run send, root/message/send help, and the unsupported `--agent` option at root and leaf positions. Every command uses a newly authored config containing only two explicit agents, an owned workspace, disabled plugins, and an owned silent log path. It contains no configured channel, model, credential, secret reference, gateway endpoint, or retained legacy owner. The child environment is a fixed non-secret allowlist and each HOME/state/config/cache/tmp directory belongs to this proof. No configuration remedy is executed and no real message/provider request is intended or possible through a configured channel.

Baseline requires exit1 and exactly one complete generic missing-owner message in all three owner cases, including the unsupported `--agent` advice. Help must succeed on each exact command surface without advertising that option. Both unsupported-option cases must fail with that exact parser error before any owner diagnostic. Full stdout/stderr bytes, hashes, argv, synthetic config, config hashes, process identity, start/finish times, join status, and acceptance are retained per case. Successful completion requires all eight managed process trees joined, unchanged authored configs, and verified removal of the owned root. Failure retains diagnostic state and raw streams, and the runner always captures a final source/build inventory even when the driver fails.

The shared message wrapper first loads its configured plugin scope. Here plugins are explicitly disabled and no channel is selected, so no channel runtime or transport is selected. `resolveCommandSecretRefsViaGateway` returns the supplied config when no configured secret references exist. The real command's ambient-owner resolver therefore has the documented ownerless explicit roster. This is source-supported reachability, not a claim that the experiment already reached it. A baseline generic error alone cannot uniquely identify which caller threw; subsequent green proof must contain the new message-specific surface and remedy to demonstrate the repaired caller was reached. The candidate will preserve this same real path, require the profiled remedy to retain `--profile proof`, and retain all help/parser controls. Typed owner regressions separately protect no dispatch on failure, successful configured/sole/legacy selection, and action normalization. Those candidate tests are not part of this baseline packet.

The complete tracked tree must be clean, including untracked files, before and after the run. Packet inputs, exact source pins, runtime/package-manager identity, and the package entry point are checked. The build inventory hashes regular files and records literal relative symlink bytes only at the inspected bundled-plugin dependency locations; it never follows those links. This producer and the managed-child owner are byte-identical to the previously inspected1d baseline contract. Any other special entry fails. Build inventory equality protects emitted bytes across CLI execution; literal-link rows do not claim to inventory external link target content.

Runner contract: `run.sh <target> <lane> <evidence> baseline`. Hosted execution requires independent exact-packet acceptance, controller integration review, and root dispatch authorization. No local target execution, live account, state migration experiment, production selection change, parser option, dependency change, or third-party send is authorized by this packet. It does not measure generic network traffic or prove actual successful channel delivery.
